신탁(D61):

계정 — 열쇠는 선택한 회사의 API 키

가입도 비밀번호도 없다. 키는 저장되지 않고 지문만 남는다. 살아 있는 키만 문이 열리니 키를 폐기하면 그 키를 쥔 누구도 못 들어온다. 들어오기 전에 만든 캐릭터는 들어올 때 계정으로 옮겨진다.
키를 새로 발급하면 옛 키가 살아 있을 때 들어와 새 키를 연결하고, 그 뒤에 옛 키를 폐기하라. 열쇠를 전부 잃으면 이 계정은 복구할 수 없다(패스키는 준비 중).

내 캐릭터와 동료

1번 칸은 네 캐릭터다. 2·3번 칸에는 함께 갈 동료를 고른다 — 준비된 동료이거나, 네가 저장해 둔 다른 캐릭터다. 출발하면 마을에서 시작한다.
성격은 키워드(최대 3개)로 고르거나 직접 쓴다 — 키워드는 문장으로 바뀌지 않고 그대로 시트에 들어간다. 배경은 자유롭게.
캐릭터 그림을 불러오는 중이다 — 먼저 이름과 성격을 정하면 된다. 그림은 준비되는 대로 자리에 들어온다.

두뇌

목록에서 고르거나 직접 입력할 수 있다. 사용 가능 여부는 API 키의 권한에 따른다.
API 키는 .env 에서 읽는다(launcher.py 가 띄운 러너에 그대로 전달).

선택한 회사의 API 키 (이 판에만)

입력한 키는 이 원정에만 사용하며 파일이나 브라우저 저장소에 저장하지 않는다. 비용은 키 주인에게 청구된다.
고급 설정 — 파티 방식 · 원정 규칙 · 마을과 던전 · 시드 · 예상 비용

스킬을 고르고, 주사위로 겨룬다

각 모험가는 스킬 2개로 시작해. 명중·피해를 주사위로 정하고, 3층에 도착하면 랜덤 스킬을 하나씩 얻어.
던전 1~3층 · 최대 1000틱 · 기본은 마을(0층)에서 시작해 던전 입구로 간다 — 아래 '마을에서 시작'을 끄면 던전 1층에서 시작

예: 1d6은 6면 주사위 하나, 피해 1~6을 뜻해. 스킬은 모험가가 직접 선택해 사용해.
사용 후 재사용 대기는 다른 행동을 완료할 때 줄어들어. 관전 화면에서 설명과 남은 대기를 볼 수 있어.

스킬을 적용하기 전의 규칙으로 비교하는 원정이야. 스킬·주사위 피해·랜덤 스킬 획득은 꺼져 있어.

계산 가정 바꾸기
토큰은 모델이 글을 나누는 단위다. 기본 계산은 1글자=1토큰이라는 가정이며, 한국어·모델에 따라 실제 수는 달라진다. 캐릭터 설정도 판단마다 입력 비용에 포함된다.
판단 1회는 캐릭터 한 명의 API 요청 1회다. 횟수는 파티 전체 합계이며 턴 수와 다르다. NPC·수첩·재시도는 별도다. 무료 할당·캐시 할인·세금 제외, 실제 청구액이나 한 판 총액이 아니다.
