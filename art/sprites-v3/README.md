# 이미지 생성 기반 전사 4방향 초안

내장 image_gen으로 직접 생성했다. 펫 제작의 일관된 캐릭터·방향별 스트립·여백 원칙을 참고했다. 펫 패키지는 아니다.

- warrior-generated-four-views.png: 생성 원본 그대로 보존. 분홍 배경 포함.
- 실제 생성 순서: 정면 / 화면 오른쪽을 보는 측면 / 뒷면 / 화면 왼쪽을 보는 측면. 요청한 측면 순서와 반대로 생성됐다.
- 헤어·옷·기본 검의 공통 특징과 네 전신의 여백 확인.
- 정확한 16×16 에셋이 아니며, 픽셀 크기도 완전히 일정하지 않다. 게임 적용·축소·배경 제거를 수행하지 않았다.
- 측면 검의 보임과 소품 일관성은 후속 검토 대상이다.
- prompt.txt에 실제 생성 프롬프트 저장.

## 정면·오른쪽 걷기

- warrior-front-walk-generated.png: 사용자가 만족한 정면 걷기 원본.
- warrior-right-walk-generated.png: 측면 걷기. 첫 결과의 비슷한 발 자세를 수정한 두 번째 생성 결과다.
- walk-comparison.html: 두 방향 동시 재생, 일시정지, 속도 변경, 프레임 선택.
- measure_walk.py: 원본 그림을 변경하지 않고 각 칸의 표시 영역만 측정한다.
- right-walk-prompts.txt: 내장 image_gen의 최초/수정 프롬프트.
- 검 뒤 다리 일부는 가려진다. 두 방향의 프레임 번호가 동일한 보행 위상을 보장하지는 않는다.
- 생성물은 미술 검토용이며 정확한 16×16이나 런타임 적용본이 아니다.

## 네 방향 걷기 추가

- four-direction-walk.html: 정면·오른쪽 승인본과 새 왼쪽·뒷면을 동시 재생한다.
- warrior-left-walk-generated.png / warrior-back-walk-generated.png: 승인한 4방향 외형과 걷기를 참고해 내장 image_gen으로 각각 생성했다. 기존 시트를 단순 반전한 결과가 아니다.
- 각 4프레임, 총 16프레임. 원본 그림은 변형 없이 보존한다.
- left-walk-prompt.txt / back-walk-prompt.txt: 실제 생성 프롬프트.
- 새 결과의 얼굴 방향·헤어·검 위치·잘림을 육안으로 확인했다. 좌측은 발이 벌어지고 모이는 자세, 뒷면은 발 높이가 달라진다.
- 방향별 원본의 보행 위상은 완전히 동기화되지 않았고 검 뒤 다리 가림이 일부 남는다. 배경 제거·정확한 게임 크기 변환·런타임 반영은 별도 단계다.
