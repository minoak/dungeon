# 공용 헤어 결합 1차 구현

2026-09-19. 승인된 몸통·공용 헤어 방향을 네 방향 정지/걷기로 검증하는 독립 미리보기다.

## 구현된 것

- 전사 남성형 몸통과 궁수 여성형 몸통 각 20프레임(정면·오른쪽·뒤·왼쪽 × 정지 1 + 걷기 4).
- 레이어드 숏컷과 일자 앞머리 장발 각 4방향. 두 헤어 모두 두 몸통에서 선택 가능하다.
- `compose.js`가 몸통 선택과 머리 선택을 독립적으로 합성한다. 목 위치에 머리를 붙이고, 장발은 정면/옆면에서 어깨 뒤로, 뒷면에서는 망토 앞으로 그린다.
- `index.html`에서 몸통/헤어, 네 방향, 걷기, 개별 프레임, 표시 크기, 몸통/머리만 보기 지원.
- `runtime/`에 정규화 부품 4장과 기존 SD 규격(480×384, 96px 셀, 발 y=91)에 맞춘 완성 조합 4장 출력.

## 보기와 재생성

프로젝트 루트에서 `node art/character-bases-v1/modular-pilot/build.mjs`로 부품을 패킹하고, `node art/character-bases-v1/modular-pilot/verify.mjs`로 검증·합성 시트·미리보기 캡처를 생성한다. 기존 `game/node_modules/playwright-core`와 설치된 Edge를 사용한다.

Vite 게임 개발 서버가 4217에서 실행 중이면 http://127.0.0.1:4217/art/character-bases-v1/modular-pilot/index.html 에서 미리보기를 연다. 검증 스크립트는 기본적으로 별도의 임시 로컬 서버를 사용하고 종료한다. `WL_PILOT_URL`로 실제 개발 서버의 주소를 지정해 같은 검증을 실행할 수도 있다.

## 제작 원본

`source/`의 PNG 4장은 내장 `image_gen` 생성 원본이며 함께 보존한 `*-prompt.txt`가 각각의 실제 프롬프트다. 원본은 수정하지 않는다. `build.mjs`는 투명 간격으로 프레임을 분리하고 알파 경계를 이진화한 뒤 최근접 보간으로 96px 셀에 패킹한다. 이미지 생성과 자동 패킹은 별도 단계다.

머리 결합점은 생성 원본에 맞춘 데이터다. 몸통은 목 상단과 발 기준을 사용하며 프레임별 몸통 확대·축소를 하지 않는다. 헤어별 배율과 결합점은 `build.mjs`의 입력 사양에 기록돼 있다.

## 검증

`verification.json`: 4조합 × 4방향 × 5프레임 = 80프레임의 비어 있지 않음, 이진 알파, 잘림 없음, 발 위치 y=91 검사 통과. 40개 몸통 프레임이 헤어 선택에 영향받지 않음을 확인했다. 브라우저에서 헤어 변경 시 몸통 유지, 몸통 변경 시 헤어 유지, 걷기 프레임 변화, 모바일 가로 넘침 없음, 스크립트 오류 없음도 확인했다.

`preview-front.png`, `preview-back.png`, `preview-right.png`를 육안으로 검토했다. 정면·옆면의 목 연결과 뒷머리의 망토 가림이 보인다. 다른 방향과 모바일 캡처도 같은 폴더에 있다.

## 아직 남은 범위

- 이 단계는 연결 검증용이며 **실제 게임·런처에는 등록하지 않았다**. 기존 캐릭터나 저장에 영향을 주지 않는다.
- 10개 몸통·14개 공용 헤어 전체 제작은 완료되지 않았다. 현재 두 체형은 각각 다른 복장으로만 검증했다.
- 궁수의 활·화살통은 결합 검증에서 제외했다. 전사의 검은 몸통에 포함돼 있다. 장비 독립 레이어는 후속 작업이다.
- 현재 머리 부품에는 얼굴이 포함돼 있다. 얼굴 유지형 순수 헤어 교체, 머리색, 모자 레이어, 긴 머리의 독립 흔들림은 아직 지원하지 않는다.
- 생성한 걷기 프레임에는 의상 디테일과 보폭의 미세한 차이가 있다. 기술 검사 통과가 최종 미술 품질 승인이나 전체 게임 통합 검증을 뜻하지 않는다.

다음 단계는 이 결합 기준으로 나머지 몸통·공용 머리를 제작하고, 기존 저장의 외형/헤어 ID 대응을 보존하면서 런처와 게임에 연결하는 것이다.
