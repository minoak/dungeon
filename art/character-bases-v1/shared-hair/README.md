# 공용 헤어 구성안

현재 적용 방향: 실제 게임 비교 후 사용자가 도트를 선택했다. 아래 14종을 공용 헤어로 만든 [characters-v2](../../characters-v2/README.md)에 바디 8종·112조합의 런처/게임 적용본이 있다. 일러스트형은 비교 실험으로 보존한다. 아래는 최초 구성안 작성 당시의 기록이다.

2026-09-19. 사용자 방향: 승인한 몸통 외형은 유지하고, 기존 직업별 머리를 모든 복장에 사용할 수 있게 공유한다. 마법사풍 머리 몇 가지를 추가한다. 남성용 헤어 종류는 여성용보다 적게 준비하되, 선택 가능 여부를 직업·성별로 제한하지 않는다.

## 확인한 현재 구조

`viewer/assets/sprites/sd/atlas.json` v2에는 검사 5개·궁수 3개·도적 3개, 총 11개의 헤어 항목이 있다. 각 PNG에는 머리뿐 아니라 몸과 장비도 포함돼 있다. `game/src/assets/sd.ts`는 `look.sprite + look.hairstyle`로 해당 완성 시트를 선택한다. 다른 복장의 시트 경로를 헤어 선택지에 넣는 것만으로 공유를 구현하면 의상까지 교체되므로 그렇게 적용하지 않는다.

## 추가 시안

`mage-hair-front.png`에 마법사풍 머리 3종을 정면 초상으로 비교했다. 내장 `image_gen` 사용, 입력은 `../mage/front-comparison.png`와 기존 검사 시트다. 정확한 프롬프트는 `prompt.txt`에 보존했다. 머리 모양에 집중하도록 모자·지팡이·로브는 제외했다. 새 디자인도 모든 복장에 제공하는 방향이다. 은보라색은 이번 시안의 색이며, 머리색 선택 기능을 구현했다는 뜻은 아니다.

## 실제 제작 순서

1. 승인한 몸통 시안들의 머리 크기·목 결합 위치·네 방향 기준을 통일한다.
2. 공용 머리를 얼굴/앞머리/뒷머리의 가림 관계를 고려해 분리 제작한다. 긴 머리가 망토·어깨 보호구에 겹치는 부분을 확인한다. 모자는 별도 장식으로 다뤄 다른 복장에 머리를 선택해도 자동으로 따라오지 않게 한다.
3. 우선 짧은 머리와 긴 머리 각각 하나를 서로 다른 복장과 두 체형에 연결해 정면·옆면·뒷면·걷기에서 결합을 확인한다.
4. 공용 목록과 합성 경로를 런처·게임·초상·저장에 연결한 후 나머지 헤어를 확장한다. 기존 저장의 복장별 헤어 ID는 대응표로 보존한다. 기존 시트는 이행 중 대체 표시로 남긴다.

레이어를 실제 화면에서 합칠지, 빌드 단계에서 완성 시트로 합칠지는 시범 결합 후 결정한다. 어느 방식이든 기존 완성 PNG를 단순히 잘라 모든 몸에 붙일 수 있다고 가정하지 않는다.

## 완료 범위

현재 목록 조사, 공용 헤어 구성안, 추가 헤어 3종의 정면 시안 제작과 육안 검토를 완료했다. 그림의 머리·얼굴이 잘리지 않고 3가지 실루엣과 모자 없는 상태를 확인했다.

후속 1차 연결 구현은 [modular-pilot](../modular-pilot/README.md)에 있다. 몸통 2종과 머리 2종을 분리한 4조합에서 네 방향·걷기와 공용 선택을 검증했다. 현재 머리 부품은 얼굴도 포함한다. 전체 14종과 게임 런처 적용은 아직이며, 기존 게임 코드·아틀라스·저장은 수정하지 않았다.
