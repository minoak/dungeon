# 마법사 복장 정면 시안

2026-09-19. 사용자가 기존 검사·궁수·도적 및 기본 여행복에 마법사 외형을 추가하도록 요청했다. 방향은 SD 및 애니메이션 서브컬처 느낌이다.

- `front-comparison.png`: 왼쪽 남성형, 오른쪽 여성형. 은보라색 머리, 짙은 보라 로브, 금색 별·달 장식, 청록색 수정 지팡이와 허리 마법서.
- 남성형은 짧은 머리와 곧은 로브, 여성형은 양갈래와 퍼지는 옷자락으로 차이를 주었다.
- 내장 `image_gen`으로 생성. 정확한 프롬프트는 `prompt.txt`에 보존했다.
- 참고 이미지: `../body-comparison.png`, `../../../viewer/assets/sprites/sd/warrior.png`, `../../../viewer/assets/sprites/sd/archer.png`.

## 적용 범위와 검토

정면 외형 시안이다. 두 인물의 전신, 지팡이·모자·로브의 잘림 여부와 기존 복장과 구별되는 실루엣을 육안으로 검토했다. 배경이 포함된 원본이며 투명 96×96 런타임 에셋은 아니다. 생성 결과의 머리·모자 높이와 몸 크기가 완전히 같지는 않아 실제 시트 제작 때 정렬과 크기 통일이 필요하다. 축소 시 금색 장식 가독성도 검토해야 한다.

게임 코드, 직업, 능력치, 런처 외형 목록은 바꾸지 않았다. 기존 4종 복장(검사·궁수·도적·여행복)에 마법사까지 포함하면 계획상 복장 5종 × 체형 2종 = 10개 기본 외형이다. 이 수는 제작 완료 수가 아니다. 각 복장의 체형 변형과 네 방향 걷기 시트 제작은 후속 작업이다.
