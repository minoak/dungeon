## 검토와 범위

6인의 정면 전신과 머리·장비의 잘림 여부, 복장별 색과 실루엣 차이를 육안으로 확인했다. 궁수의 활과 시위, 전사의 검, 도적의 단검이 보인다. 생성 결과는 픽셀 단위 정렬이나 몸 크기가 완전히 동일하지 않으며, 원본 스프라이트를 그대로 추출한 것도 아니다. 실제 96px 크기에 맞출 때 비율 통일과 세부 장식 단순화가 필요하다.

정면 콘셉트이며 배경 포함 원본이다. 네 방향 걷기 시트, 투명 배경 처리, 파츠 분리, 런처 등록, 장비와의 연결은 아직 수행하지 않았다. 직업에 외형을 강제로 묶는 기능도 추가하지 않았다. 현재 마법사를 합쳐 전투 복장 4종의 남녀 정면 시안 8종을 볼 수 있고, 별도 기본 여행복 정면 시안 2종이 있다.
