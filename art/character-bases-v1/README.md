# SD 기본 체형 정면 시안

현재 적용본은 [characters-v2](../characters-v2/README.md)다. 도트 바디 8종과 공용 헤어 14종이 런처/게임에 연결되었다. 아래는 최초 정면 시안 제작 당시의 기록이다.

2026-09-19. 남성형·여성형 몸을 구별할 수 있는 기본 외형 연구.

- `body-comparison.png`: 왼쪽 남성형, 오른쪽 여성형. 같은 계열의 튜닉·바지·부츠를 입혀 어깨·허리·팔다리 실루엣을 비교한다.
- 기존 SD 검사·궁수 시트를 그림체 참고로 사용했다. 첫 결과의 긴 팔다리를 줄여 큰 머리와 짧은 몸의 SD 비율로 보정했다.
- 사용자 확인: “남자 머리 스타일은 여성보다 작게”는 **남성용 헤어스타일의 종류를 적게**라는 뜻이다. 남성 머리나 머리카락 자체의 크기를 줄이라는 뜻이 아니다.
- 제안한 첫 헤어 구성은 남성형 2종·여성형 4종이다. 정확한 스타일은 아직 확정하지 않았다.

## 범위

정면 미술 시안이며, 게임 적용용 투명 스프라이트 시트나 조립 가능한 몸 레이어가 아니다. 배경이 포함된 생성 원본이다. 런처·아틀라스·캐릭터 저장 형식은 수정하지 않았다.

실제 적용에는 기본 체형별 4방향, 정지·걷기 프레임, 의상과 머리의 방향별 결합 검토가 남아 있다. 현재 SD 헤어 선택지는 전체 몸을 포함한 시트이므로 독립 헤어 부품처럼 합성할 수 없다. 기존 성별·직업·능력치와 외형 선택의 독립성은 유지한다.

## 제작과 검토

내장 `image_gen` 사용. 최종 생성 프롬프트 및 초기 생성 프롬프트는 `prompts.txt`에 보존한다. 현재 그림체 참고는 `../../viewer/assets/sprites/sd/warrior.png`, `../../viewer/assets/sprites/sd/archer.png`이다.

검토: 두 인물의 정면 전신·의상·짧은 SD 비율·체형 차이를 육안으로 확인했다. 픽셀 단위 동일 크기 정렬이나 실제 96px 게임 화면의 가독성은 아직 검증하지 않았다.
