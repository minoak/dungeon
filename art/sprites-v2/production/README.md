# 캐릭터 전체 1차 제작본

2026-09-07. 사용자 warrior-16-work (3).json을 approved-warrior-front.json으로 보존하고 기준으로 삼았다.

## 보기와 수정

- index.html: 모든 머리·직업을 4방향 정지/걷기로 확인. 서버 없이 열린다.
- ../parts-editor.html: 머리·직업·방향·프레임을 선택해 직접 수정한다.
- PNG 720장: 머리 12종 × 직업 3종 × 방향 4종 × (정지 1 + 걷기 4).
- 조합 시트 36장: 각 머리/직업/sheet.png, 80×64. 열은 정지/걷기0/1/2/3, 행은 front/left/back/right.
- 직업별 contact.png와 대표 M1 걷기 GIF를 함께 제공한다.

## 유지하는 기준

- M1 전사 정면 정지는 사용자의 승인 행렬과 모든 픽셀이 같다.
- 정면 눈: x=5,9 / y=7,8. 측면: 왼쪽 x=5, 오른쪽 x=10 / y=7,8. 뒷면에는 눈이 없다.
- 머리 위치는 정지/걷기에서 고정한다. 발 한쪽은 항상 마지막 행에 닿는다.
- 직업별 기본 무기는 고정 외형이다. 장비 데이터와 연동하지 않는다.
- 직접 배치한 팔레트 행렬을 출력하며 생성 이미지 축소를 사용하지 않는다.

## 수정 파일

편집기는 프레임별 수정·비교 기준을 브라우저에 임시 보관한다. 전체 수정 묶음 저장으로 JSON을 내보내고 다시 불러올 수 있다. 현재 조합 시트 저장은 수정 내용을 반영한다. 다른 프레임으로 수정이 자동 복제되지는 않는다. index.html은 기본 초안만 보여준다.

## 검증과 한계

720개 프레임의 눈 위치·발바닥·16×16 크기·알파 0/255, 승인 정면 일치 검사 통과. 실제 브라우저에서 선택 전환, 수정 보존, 초기화, 시트/묶음 저장과 복원, 페이지 오류 없음 확인.
걷기는 발만 교대로 드는 간단한 4프레임이다. 머리 12종의 방향별 특징과 긴 머리/무기 겹침은 미술 검토 대상이다. 완성품 승인이나 게임 적용까지 완료했다는 뜻은 아니다.
sprites.json은 문자 팔레트 기반 버전2로 기존 런타임 버전1의 직접 교체용이 아니다. 기존 게임 파일은 변경하지 않았다.
