# 직업별 몸통 · 머리 중심 시안

2026-09-07. 현재 산출물은 정면 외형 설계 시안이며 게임용 픽셀 에셋이 아니다.

- 머리: 기존 승인 시안 M1을 참고해 동일한 머리로 직업 차이를 비교.
- 비율: 머리 약 2/3, 짧은 몸 약 1/3.
- 전사: 갑옷과 고정 검. 도적: 가죽 복장과 고정 단검. 궁수: 녹색 복장과 고정 활·화살통.
- 몸통은 성별 대신 직업으로 구분한다. 무기는 외형에 고정하며 장비 변화와 연동하지 않는다.
- job-body-concept.png는 생성 이미지로, 정확한 16×16 또는 32×32 규격을 보장하지 않는다. 축소만으로 게임에 적용하지 않는다.
- 기존 런타임과 sprites-v1은 변경하지 않았다.

## 제작 상태

완료: 기존 변환 구조 확인, 정면 직업 3종의 비율·외형 시안.
남은 작업: 실제 픽셀 격자에 맞춘 정면 제작 및 검토, 4방향·걷기 확장, 머리 조합과 런타임 적용.
현재 시안도 머리 음영이 실제 16×16보다 세밀하므로 디테일 보존을 보장하는 자료로 사용하지 않는다.

제작 도구: 내장 image_gen. 생성 프롬프트는 prompt.txt에 보관.

## 실제 픽셀 비교 · 전사 정면

- warrior-compare.html: 표시 크기·배경·격자 조절, 동일 표시 크기 비교, PNG 다운로드. 서버 없이 열 수 있다.
- warrior-16.png / warrior-32.png: 정확한 16×16 / 32×32 투명 PNG. 알파 0/255 검증 완료.
- warrior-comparison.png: 확대 및 32·48·64px 표시 비교 이미지.
- warrior-pixels.json: 직접 배치한 팔레트 행렬. 기존 프로젝트의 인덱스 픽셀 방식으로 제작했다.
- render_comparison.py: 행렬을 PNG로 출력하고 크기·알파를 검사한다.

32px는 16px와 같은 기본 실루엣을 바탕으로 세부 픽셀을 조정한 안이다. 자동 확대만으로 이런 디테일이 생긴다는 뜻은 아니다. 16px는 턱까지 11행, 몸·발은 5행이다. 실제 게임 적용과 나머지 직업·방향·걷기는 아직 하지 않았다.

## 16픽셀 작업실

pixel-editor.html을 브라우저에서 연다. 설치나 서버 없이 작동한다.
- 연필·지우개·색 집기·드래그·선택적 좌우 대칭.
- 드래그 한 번 단위의 실행 취소/다시 실행(최근 100회).
- 16·32·48·64px 동시 표시, 수정 전후 비교, 변경 픽셀 수.
- 현재 모습을 비교 기준으로 지정하거나 기준으로 복원.
- 정확한 16×16 투명 PNG와 다시 편집 가능한 JSON 저장/열기.
- 브라우저 임시 저장. 파일로 내보낸 JSON이 장기 보관용이다.
- 방향키·스페이스 편집, Ctrl/Command+Z 및 Shift+Z 되돌리기.

검증: Edge 브라우저에서 대칭 칠하기, 드래그 지우기, 취소/재실행, 새로고침 복원, PNG/JSON 다운로드, JSON 복원, 잘못된 입력 보존, 모바일 가로 넘침 없음, 페이지 오류 없음 확인. 다운로드 PNG의 16×16 크기와 알파 0/255 확인.
기존 전사안을 편집 시작점으로 제공한다. 최종 캐릭터 디자인 확정과 게임 반영은 별도 단계다.
