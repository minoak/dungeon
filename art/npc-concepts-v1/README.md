## 제작 상태

원본 크기의 정면 외형 검토용 이미지다. 기존 런타임보다 묘사가 촘촘하고 신체 비율이 길어, 96px 게임용으로 만들 때 비율과 도트 밀도 정리가 필요하다.
4방향, 걷기 프레임, 발 위치 정렬, 런타임 등록은 아직 포함하지 않는다.
세 이미지의 외형, 전신 표시, 머리와 의상 및 소품의 구분을 시각적으로 확인했다.
투명 PNG 생성 요청을 사용했으며 결과 원본을 수정 없이 보존했다.
