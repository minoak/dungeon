# 공용 헤어를 사용하는 도트 캐릭터

2026-09-19. 게임 화면에서 일러스트형과 기존 도트를 비교한 뒤, 사용자 요청에 따라 도트 스타일로 확정했다.

## 적용 결과

- 전사·도적·궁수·마법사 의상에 남성형/여성형 바디를 각각 마련했다. 바디 8종과 공용 헤어 14종으로 112조합이다.
- 모든 조합은 96px 셀, 480×384 투명 시트, 정면/오른쪽/뒷면/왼쪽 4방향, 정지+걷기 4프레임이다. 발 기준은 y=91, 이진 알파와 최근접 보간을 사용한다.
- 승인된 마을 맵에서는 캐릭터와 NPC 표시 배율을 1.6배에서 2.0배로 확대했다(기존 대비 25%). 발 기준점과 이동 좌표는 유지하며, 이름표/말풍선도 표시 크기에 맞춘다. 던전과 구형 맵의 배율은 기존 1.0배다.
- 런처의 신규 외형 목록에 8종을 표시한다. 바디를 바꿔도 공용 헤어 id를 유지하며 저장/불러오기까지 연결했다.
- 저장 형식은 기존 `look.sprite`와 `look.hairstyle`을 그대로 쓴다. `sd-warrior-male` 등 바디 id와 `wavy-twintails` 등 공용 헤어 id를 저장한다. `default`는 각 바디 기본 헤어의 호환 별칭이며 중복 선택지로 표시하지 않는다.
- 머리 선택에 따라 몸통을 다시 생성하지 않는다. 하나의 바디 원본에 동일한 머리 부품을 합성하므로 헤어 변경이 의상을 바꾸지 않는다.
- 실제 캐릭터 직업·성별·능력치와 외형 선택은 독립적이다. 마법사 의상 추가는 마법 직업의 전투 규칙이나 스킬 구현을 뜻하지 않는다.
- 기존 3종 도트와 일러스트 실험 프리셋은 저장본/리플레이 호환을 위해 유지한다. 새 선택 목록에서는 숨기고, 그 외형의 기존 저장본을 불러오면 해당 선택지는 표시한다.

## 미리보기

Vite 4217 실행 중:

- [조합 의상실](http://127.0.0.1:4217/art/characters-v2/index.html): 바디별 헤어, 전체 공통 헤어, 방향, 걷기 비교.
- [머리 수정 전후 비교](http://127.0.0.1:4217/art/characters-v2/head-review/index.html): 동일한 바디에서 목 연결, 헤어 정렬, 걷기 움직임을 비교한다.
- [마을 크기 확인](http://127.0.0.1:4217/game/?run=art/characters-v2/preview-run.jsonl&focus=1&t=1): 공개 지도 검토용 더미 자료에 외형 8종을 배치했다. 실제 플레이 기록이 아니다.

`preview-*.png`, `town-normal.png`, `town-close.png`, `launcher-preview.png`는 브라우저 검증 캡처다. 기존에 실행한 런처가 외형 사전을 캐시했다면 재시작 후 새 조합을 저장한다. 실제 실행 중인 판은 변경하지 않았다.

## 원본과 빌드

내장 **image_gen**으로 바디 시트 6장과 헤어 시트 3장을 추가 제작했다. 최종 프롬프트는 `source/*-prompt.txt`, 생성 원본은 `source/*.png`에 보관한다. 이미 제작한 남성형 전사/여성형 궁수 바디, 마법사 숏컷/장발 부품은 `../character-bases-v1/modular-pilot/`에서 재사용한다. `catalog.json`이 원본과 이름/기본 헤어를 연결한다.

`build.mjs`는 생성 이미지의 알파 실루엣을 분리하고 목과 발 기준을 정렬해 `runtime/` 부품을 만든다. 기존 파일의 얼굴이나 몸을 임의로 그리는 처리는 없다. 긴 머리는 정면/측면에서 어깨 뒤에, 뒷면에서는 망토 위에 배치한다. 실제 게임 파일은 `../../viewer/assets/sprites/sd/shared/`에 합성 출력하고 atlas에 등록한다. 게임과 런처는 같은 완성 시트를 사용한다.

```powershell
node art/characters-v2/build.mjs
node art/characters-v2/make-preview.mjs
node art/characters-v2/verify.mjs
node art/characters-v2/verify-heads.mjs
python verify_sd_assets.py
python verify_launcher.py
npm --prefix game run build
npm --prefix game run smoke
```

## 검증과 범위

추가 미술 기준: 사용자가 마법사 일자 앞머리 장발의 거의 보이지 않는 목을 선호했다. 해당 헤어는 유지하고, 다른 헤어는 `chinY`로 턱을 옷깃에 맞춘 뒤 앞쪽 목 부품이 가슴 위에 다시 그려지지 않도록 합성 범위를 제한했다. 뒷면의 긴 머리는 길이를 보존하기 위해 전체를 망토 위에 표시한다. 바디는 그대로 유지한다. 아래 4px 연결점 보정은 최초 보정 기록이며, 현재 `chinY`가 있는 헤어는 턱 기준 배치를 우선한다.

머리 보정 후에는 피부색 자동 추정 대신 `catalog.json`의 방향별 연결점을 사용한다. 금발 하이라이트를 목으로 오인하던 리본 포니테일·땋은 머리의 위치/크기를 바로잡고, 양갈래의 중심도 정렬했다. 전체 헤어는 목 연결점을 옷깃 안으로 4px 겹치며, 걷는 동안 1px 상하 움직임을 더한다. 머리 움직임은 방향별 정지 자세를 기준으로 계산해 원본 바디의 미세한 높이 변화와 상쇄되지 않게 했다. 긴 머리는 옷깃까지 앞쪽에, 그 아래는 몸 뒤쪽에 그린다. 바디 원본과 패킹 결과는 바꾸지 않았다.

`head-review/before/`는 비교용 수정 전 부품과 합성 코드다. `verify-heads.mjs`가 바디 8장의 SHA-256 동일성, 448개 걷기 조합의 머리 움직임, 실제 게임 텍스처와 미리보기 2,240프레임 일치를 검사한다. 결과는 `head-review/verification.json`에 저장한다. 원본 그림의 재생성이나 픽셀 리터치는 하지 않았으며, 합성 위치와 프레임별 배치를 보정했다.

- `build-report.json`: 112조합 × 20프레임 = 2,240개, 빈 프레임/경계 잘림/발 위치/이진 알파 검사.
- `verification.json`: 실제 Phaser 텍스처·애니메이션 2,240프레임, 헤어 14종에서 바디 160프레임 불변, 런처의 헤어 유지·저장·다시 불러오기, 구판 재생, 모바일 가로 넘침 없음, 브라우저 오류 없음.
- `verify_sd_assets.py`: 모든 외형 값의 저장 검증 및 더미 러너의 외형 변경 전후 물리 진행 동일. `verify_launcher.py`와 게임 빌드 통과. 게임 스모크는 31개 통과, 0개 실패, 리플레이에 해당하지 않는 라이브 배지 1개 생략이다.
- 검증은 LLM 게임 호출 0회, 임시 런처 저장소를 사용했다. 이미지 제작에는 내장 이미지 생성 도구를 사용했다.
- 헤어 부품에는 얼굴이 포함되어 있다. 머리/눈 색은 고정이며 독립 색상 변경 기능은 이번 범위에 포함하지 않는다.
- 궁수와 마법사의 바디는 공용 머리 연결을 위한 의상 중심이며 활·화살통·지팡이·마법사 모자는 포함하지 않는다. 별도 무기/모자 장비 레이어는 아직 없다.
