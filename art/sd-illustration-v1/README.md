# 일러스트형 SD 전사 — 게임 적용 1종

후속 결정: 실제 게임 비교 후 사용자가 도트 스타일을 선택했다. 현재 신규 캐릭터 외형은 [characters-v2](../characters-v2/README.md)의 바디 8종·공용 헤어 14종이다. 이 실험 프리셋은 신규 선택 목록에서 숨기고 기존 저장본/비교 리플레이 호환용으로 보존한다. 아래의 선택·검증 기록과 `verify.mjs`는 당시 공개 선택지였던 상태를 기준으로 한다.

2026-09-19. 사용자 피드백: 강제 도트화 결과가 흐릿하게 보이므로, SD 비율과 서브컬처 그림체를 유지하면서 매끄러운 일러스트로 표시한다.

## 결과와 선택

- 런처 외형에 **SD 전사 · 일러스트** 추가. 선택 ID는 `sd-warrior-illustration`, 현재 헤어는 갈색 레이어드 숏컷 1종이다. 기존 외형을 자동 교체하지 않는다.
- 원본에서 몸통과 머리를 따로 제작·보관하고, 네 방향 × 정지 1 + 걷기 4를 합성했다.
- 런타임은 256px 셀, 1280×1024 RGBA 시트다. 알파 경계와 부드러운 선을 보존하며, 96px로 줄여 저장하거나 이진 알파/최근접 도트 변환을 적용하지 않는다.
- 화면상의 크기는 기존 96px 캐릭터와 동일하게 정규화한다. 새 외형 텍스처만 선형 보간을 사용하고 기존 도트는 최근접 보간을 유지한다. 이름표·말풍선·발·선택 원의 크기도 해상도와 분리했다.
- 런처 및 구형 관전 뷰어도 프리셋별 셀 크기를 읽는다. 실제 판을 시작하지 않는 임시 런처에서 선택·저장·다시 불러오기까지 확인했다.
- 이미 실행 중인 런처가 외형 목록을 캐시했다면 런처 재시작 후 선택/저장한다. 실행 중인 실제 판은 이번 작업에서 종료하거나 변경하지 않았다.

## 실제 마을 비교

Vite 개발 서버 4217에서 [게임 비교](http://127.0.0.1:4217/game/?run=art/sd-illustration-v1/preview-run.jsonl&focus=1&t=1)를 연다. 왼쪽 캐릭터는 기존 도트, 오른쪽은 새 일러스트 SD다. 게임의 확대 버튼으로 가까이 볼 수 있다.

`town-normal.png`와 `town-close.png`는 실제 게임 씬에서 동일한 표시 크기로 찍은 비교다. `launcher-preview.png`는 새 외형을 고른 런처 화면이다. 비교 판은 기존 공개 지도 검토용 더미 자료로 만들었으며 개인 플레이 기록이 아니다.

## 제작 원본과 재생성

내장 **image_gen** 사용. `warrior-concept.png`는 픽셀 질감 없이 다시 그린 전사 정면 시안이다. `source/warrior-body.png`는 머리 없는 몸통 20프레임, `source/warrior-head.png`는 머리 4방향이다. 실제 프롬프트는 `source/*-prompt.txt`에 보존했다.

`node art/sd-illustration-v1/build.mjs`는 원본의 주요 알파 연결 영역과 부드러운 가장자리를 보존해 분리하고, 떨어진 생성 잔여물을 제거한 뒤 고품질 축소로 패킹한다. 정규화 부품은 `runtime/`, 게임용 합성 시트는 `viewer/assets/sprites/sd/warrior-illustration.png`에 쓴다. 원본에는 손대지 않는다. `build-report.json`에 원본 영역·결합점·배율을 기록했다.

`node art/sd-illustration-v1/make-preview.mjs`는 지도 검토용 더미 판에서 비교 판을 생성한다. `node art/sd-illustration-v1/verify.mjs`는 별도 Vite 서버와 임시 저장소의 런처를 띄워 검사하고 종료한다.

## 검증과 한계

`verification.json`: 20프레임 잘림·발 위치·부분 알파, 기존/신규 동일 표시 크기, 외형별 보간, 초상화, 네 방향 걷기, 기존 판으로 전환, 임시 런처의 선택·저장·불러오기 통과. 실제 마을의 일반/확대 화면도 육안으로 확인했다. 판 전환 시 같은 캐릭터 번호에 이전 외형이 남던 문제도 수정했다.

추가 통과: `npm --prefix game run build`, `python verify_sd_assets.py`(신규 외형의 run_meta 전달 및 게임 진행 불변 포함), `python verify_launcher.py`, `npm --prefix game run smoke`(31 통과, 0 실패, 리플레이 환경의 라이브 배지 1개 생략). 게임 검증에는 실제 LLM 호출을 사용하지 않았다. 이미지 생성은 별도 내장 image_gen 호출이다.

원본 해상도가 높아도 마을 전체 보기에서 작은 캐릭터의 모든 장식을 읽을 수 있는 것은 아니다. 현재는 전사 남성형과 숏컷 한 조합이다. 얼굴은 머리 부품에 포함돼 있고, 다른 체형·복장·공용 헤어의 일러스트 전환은 아직 남았다. 생성한 보행 프레임의 보폭·갑옷·망토 디테일은 미술 정돈 대상이다. 원래 착용 장비와 그림 장비가 자동 연동되는 기능도 이번 범위가 아니다.
