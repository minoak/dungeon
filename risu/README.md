# risu/ — RisuAI 플러그인 작업대

원더랜드의 RisuAI 이주(JS) 작업 폴더. 2026-07-29 개설.
방향: 카드(로어북 덩어리)가 아니라 **플러그인 v3** — 풀스크린 컨테이너 안에서
엔진(JS 포팅)+뷰어가 돌고, 두뇌 콜은 사용자 자기 키(`//@arg`)로.

## wonderland-spike.js — 관문 계측기 (게임 아님)

문서로 확인한 세 관문이 **실물에서 여는지** 재는 최소판. 이 결과가 이주 견적의 근거가 된다.

### 설치

1. RisuAI 설정 → 플러그인 → `wonderland-spike.js` 파일 추가 (웹리스면 파일 업로드)
2. 플러그인 설정에 `gemini_key` 칸이 생기면 → Gemini API 키 입력
   (aistudio.google.com 발급, 무료 티어 가능)
3. 채팅 화면에서 **[원더랜드]** 버튼 클릭 (없으면 설정 메뉴에 "원더랜드 스파이크" 폴백)

### 확인 체크리스트 — 결과를 알려줘

| # | 관문 | 통과 기준 | 결과 |
|---|---|---|---|
| 0 | 플러그인 로드 | 설정에 "원더랜드 스파이크" 표시, `gemini_key` 입력칸 생성 | |
| 0' | 전역 API 이름 | 화면 상단에 `전역 API = risuai`(또는 Risuai) 표시 | |
| ① | 컨테이너·렌더 | [원더랜드] 버튼 → 풀스크린 → 5×5 격자(@·+)가 보임 | |
| ①' | 이벤트 | 화면 안 버튼 3개가 눌림(클릭 반응) | |
| ② | 두뇌 콜 | [② 두뇌 콜 테스트] → `nativeFetch 성공 (N초): {...JSON}` + 파싱 줄 | |
| ③ | 저장 | [③ 저장 테스트] → "이번이 N번째" — **RisuAI 재시작 후 다시 누르면 N+1** | |
| — | 닫기 | [닫기] → 채팅 화면 복귀 | |

실패하면 화면 하단 로그(붉은 줄)를 그대로 복사해서 알려줘 — 로그가 다음 수를 정한다.

### 이 스파이크가 확정하는 것

- **①이 열리면**: 기존 웹 뷰어를 iframe에 이식하는 경로 확정 (SafeElement 제약 무관)
- **②가 열리면**: `brains.py` gemini 어댑터의 JS 이식 경로 확정 (같은 헤더·같은 thinking 규율)
- **③이 열리면**: 판 기록(스트림 JSONL)·시트 저장 경로 확정
- 셋 다 열리면 → 엔진 포팅+verify 재구축 견적으로 진행 ("이주 vs 사본"은 별도 토론)
