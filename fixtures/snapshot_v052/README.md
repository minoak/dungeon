# 옛 꼴 스냅샷 — v0.5.2 코드가 쓴 그대로

`verify_class_foundation.py` ⑧이 읽는 고정 자료다(p0.5.3, 2026-10-12). 스냅샷에 판 번호(`state_version`)가 생기기 **전** 코드가
실제로 남긴 몸이라, "옛 스냅샷을 새 꼴로 올려 이어간다"를 흉내가 아니라 진짜 옛 파일로 확인한다.

| 파일 | 무엇 |
|---|---|
| `snapshot.pkl` · `snapshot.json` | 판형 `version` 1, `state_version` 없음. 몸에 `mind`·`search_prof`·`steal_prof` 없음 |
| `stream.jsonl` | 그 판의 기록(스냅샷 자리까지 + `stopped` 줄) — 이어가기가 run_meta 를 대조하고 자리에서 자른다 |
| `env.json` | 그 판의 환경변수(론처가 실판 구성에 주는 값 + 두뇌 더미·40틱) — 이어갈 때 세계 지문이 같아야 한다 |
| `snapshot_v052.py` | v0.5.2 의 `snapshot.py` 바이트 그대로 — "옛 코드가 새 스냅샷을 거절한다"를 옛 로더로 직접 확인한다 |

만든 법: v0.5.2 커밋(ed3428d)을 리포 밖에 풀고(`tools/baseline.py` 의 사본), 론처가 실판 구성(마을·파티 결성·부활·스킬·concept 맵,
민옥의 10-11 판과 같은 옵션)에 주는 환경변수로 러너를 돌려 6틱째에 곱게 멈췄다(수첩 0장 — 사람이 누른 멈춤과 같은 길). 시드 7 · 기본 파티 · 더미 두뇌 · 0콜.

⚠️ 피클이다 — 읽으면 그 안의 클래스 경로(dungeon_gm·social_reactions·bestiary …)로 객체를 되살린다. 이 폴더의 파일은 리포가 만든 자료라
코드와 같은 신뢰 급이다(밖에서 받은 .pkl 을 여기 두지 말 것). 엔진의 클래스 이름이 바뀌어 이 파일이 안 읽히게 되면 ⑧이 빨간불을 켠다 —
그건 "옛 판을 못 이어간다"는 뜻이므로 이관 함수를 더하거나(snapshot.MIGRATIONS) 그 사실을 패치 노트에 적는다.
