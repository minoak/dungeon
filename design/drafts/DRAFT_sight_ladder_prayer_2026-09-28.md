## B. 합의된 것

- **거리 사다리**: 보이면 이름 → 2칸 상세정보 → 1칸 상세정보 + 흔적(퀘스트·비밀을 여는 알림). 1칸 알림은 알림일 뿐이고, 실제로 걸리는 건 캐릭터가 행동을 골랐을 때다.
- **동료 관점**: 캐릭터마다 자기 위치에서 따로 받는다(2칸 밖의 동료는 상세를 못 본다).
- **아이템보다 비밀 정보**: 사다리 끝에 두는 건 퀘스트 물품이 아니라 비밀. 나중에 NPC 에이전트가 가져온 정보로 퀘스트를 내는 길로 이어진다.
- **처음 판은 작게**: 석상 하나 · 비밀 하나 · 가리키는 것 하나.
- **기도**: 신전에서 신과 이어 주는 정보를 얻으면 기도가 열린다. 기도로 신에게 도움을 청한다.
- **신 = 이 에이전트를 굴리는 사용자**(관전자가 아니다). 기도가 오면 에이전트↔사용자 양방향 채널이 게임 안에 열리고, 메신저 모양이다.
- **첫 단계 = 사용자가 자신이 어떤 신인지 정의한다.**
- **신의 말은 명령이 아니다**(D61 "요청이지 명령이 아니다 — 신은 절대자가 아니다"를 잇는다). 따를지는 캐릭터가 성격대로 정한다.
- **메신저 문장에 길이 상한.**
- **답장은 별개 세션**(파트너 제안) — 틱을 기다리지 않고 메신저에서 자유롭게 주고받는다.

## C. SilenceBreaker 제안 (파트너 확인 전)

- **시야 엔진은 안 건드린다.** 시야 엔진 = 무엇이 보이나(`seen`), 사다리 = 보이는 것을 얼마나 자세히 말하나(관측 조립). D75 가 이미 이 층에서 거리로 가른다. 시야 엔진을 건드리는 경우는 "멀리서는 있는지조차 모른다"를 원할 때뿐.
- **거리 숫자는 처음엔 전 오브젝트 공통**(2칸·1칸). 오브젝트마다 달라야 할 까닭이 실제로 나오면 연다.
- **각 단계 문장에 '더 가까이 가면 더 있다'는 흔적**을 둔다. 없으면 다가갈 까닭이 없어서 사다리가 안 쓰인다. (지금 석상 trait "받침돌에 글이 새겨져 있다"가 이미 그 꼴.)
- **보이는 것 = 거리가 정함, 아는 것 = 기억이 정함.** 프롬프트엔 둘 중 자세한 쪽 + "(전에 읽음)" 표식. 들은 것(동료의 말)도 아는 것에 든다.
- **비밀 = 번호 + 문장 + 가리키는 것**(세계 안의 실제 무엇). 장부에 "누가 어떤 비밀을 아는지"를 적는다. 까닭 = LLM 은 비밀을 지어낼 수 있다 — 나중에 NPC 가 퀘스트를 낼 때 장부의 비밀만 근거로 삼아야 빈 곳으로 보내는 퀘스트가 안 생긴다.
- **1칸에선 흔적까지만, 비밀은 행동으로**: 석상의 '읽기'(D89) = 받침의 공개된 글, '살펴보기'(D90) = "받침 뒤에 누가 따로 긁어 놓은 자국" → 비밀. 까닭 = 지나가는 사람 누구나 얻는 비밀은 비밀이 아니다.
- **비밀의 쓰임 후보**: "알면 판정 없이 보인다"(`concealed`·`perception_gate`). 또는 가리키는 것이 사람 — 석상의 주인이 신전 벽의 '돌아오지 못한 모험가' 중 하나라면, 비밀을 아는 캐릭터만 벽에서 그 이름을 알아본다.
- **비밀의 내용(누구의 상인가 · 마을 이름은 누가 붙였나)은 세계 설정이라 파트너가 정한다.** 초안이 필요하면 SilenceBreaker 가 몇 개 쓴다.
- **'기도' 이름 충돌**: D74 에서 이미 '성직자에게 기도 → 축복의 물약'. 새 기도와 잇는 안 — 성직자가 "신전에 오지 않아도 그분께 닿는 법"을 알려 준다(신전 기도 = 성직자를 거침, 새 기도 = 어디서든 신에게 직접).
- **신 정의 → 옛 문장이 참이 된다**: 신전 history 의 "너희와 계약한 그분" = 굴리는 사용자. 정의 전까지는 이름 없는 그분. 공유 세계가 되면 사용자마다 다른 신 = 다신교가 저절로 생긴다.
- **신의 답은 처음엔 말만**(기적·회복은 나중 갈림길). 기적이 되면 사용자가 게임에 손을 대는 힘이 생긴다.
- **아무도 답하지 않을 때**: 침묵을 정직하게("기도했다. 아직 답이 없다"), 캐릭터는 답을 기다리며 멈추지 않는다.
- **별개 세션이면 카야가 둘이 된다 → 기억 다리를 양쪽으로.**
  - 게임 → 메신저: 메시지마다 지금 상태(HP·있는 곳·최근 사건 몇 줄)를 붙인다(글자만, 추가 콜 0).
  - 메신저 → 게임: 나눈 말의 요지를 캐릭터 장부에 적고, 다음 관측에 "신과 나눈 말" 한 줄. 약속을 지킬지도 캐릭터가 정하되 어긴 것은 기록에 남는다.
  - 실패 장면: 메신저의 카야 "지금 바로 마을로 돌아가겠습니다" ↔ 게임의 카야는 모르고 3층으로 내려간다.
- **공개 서버의 자유 문장**: 길이 상한 + Gemini PROHIBITED_CONTENT 에 판 전체가 막히지 않게(09-15 전례).

## D. 열린 질문

1. 파트너의 "캐릭터의 상태와는 별개로"가 **차례를 기다리지 않는다**는 뜻인가, **메신저의 캐릭터가 게임 상황을 몰라도 된다**는 뜻인가. (SilenceBreaker 는 전자에 찬성, 후자에 반대 — §C 실패 장면.)
2. 메신저 콜을 운영자 키 판(판당 400콜)에 셀지, 따로 상한을 둘지 — **붙일 때 정한다**(파트너 A-8).
3. 파트너가 기억한 '이스터에그'가 석상 쪽인가 신전 쪽인가(리포·메모리에 '이스터에그'로 적힌 것은 없다 — §E 후보 둘).
4. 신의 답이 말만인가, 기적도 되나.
5. 채널이 열린 뒤 사용자가 먼저 말을 걸 수 있나(메신저라면 아마 그렇다).
6. 신 정의는 어디에 붙나(계정 · 캐릭터 · 판) — 판을 넘어 남는가('계약'이라면 남아야 자연스럽다).
7. 기도를 매 순간 하지 않을 까닭은 무엇인가(세계 안의 값 · 신의 침묵 — 규칙으로 막지 않는 방향으로).

## F. 순서 후보 (SilenceBreaker 제안 · 미합의)

1. 거리 사다리 일반화(1칸 단계 추가) + 아는 것 장부 — 0콜 게이트.
2. 석상 비밀 하나 프로브 — 흔적을 보고 다가가 살펴보나 · 알고 나서 따라가거나 말하나(3~4콜).
3. 신 정의 프로브 — 같은 장면에 신 정의만 둘(전쟁의 신 / 자비의 신), 기도·행동이 달라지나(~4콜).
