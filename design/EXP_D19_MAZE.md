# 실험 사전등록 — "보고 이동"(D19) 미로 판정 (2026-07-11)

**발단(창립 관찰, 민옥)**: "이동이 수동적이다 — 허허벌판에서 어디로 갈지 근거가 없다."

고정**한다(사전등록 — 리모컨·페르소나·ascii 프로브 선례).

시작 방 → 본 복도(T자 갈림길 2, 막다른 길 3) → 작은 방(문 3) → **시야(5)보다 큰 공동
15×17**(중심 (38,11)에서 벽 불가시 검증) → 출구(공동 북동).
1인(두란), 몹 0·함정 0 — 순수 이동만 측정. 150틱, seed 7, 리모컨 기본(menu=1).

- 공동 사각형 = (31..45, 3..19). 계측기 `maze_metrics.py` 와 지도가 한 몸(지도 수정 시 갱신).

  **양 암 동일 조건**. 암 B 구현에는 기하 기반 구역 분류(방/복도)가 선행되어야 한다.

## 암

- **암 A(현행)**: 오늘 HEAD 의 wire/어휘 그대로. ways=방향·거리·발자국뿐, 구조 침묵.
- **암 B(D19 패키지 — 2026-07-12 확정판 기준, HARNESS_DESIGN.md D19 갱신 블록이 정본)**:
  공간 어휘(방·문·복도·갈림길·막다른 곳) + **구조는 훤히·내용물은 시야대로**(들어선 공간의
  뼈대는 확정 제공 — 안 보이는 출구도 핑 종점) + wire 트리 직렬화(층 > 공간 > 8방위 슬롯,
  빈 방향 발화, 출처 딱지, 1칸=1m) + 탐색 종점 개정("새 명사가 나타나면 멈춤") + **처음 방
  진입=정지·판단 요청**. (원안의 장소 딱지 3단은 내용물 확인 딱지로 축소 — 확정판 개정.)

## 지표

주지표(판정용):
1. **탈출 틱** (escaped 기준 — timeout 이면 그 판은 최하위로 취급)
2. **재방문율** — 이미 밟은 칸으로의 걸음 / 전체 걸음 (헤맴의 숫자)
3. **공동 소요 틱** — 공동 진입 → 탈출 (허허벌판 문제의 직접 측정)

보조지표(판정 미사용, 관찰 카드):
- reason 의 공간 근거 인용(손세기 — "막다른 길이라", "안 가 본 문으로" 류)
- 폴백률·결정 수 (타임아웃 소음 전례 — 판정에 쓰지 않는다)
