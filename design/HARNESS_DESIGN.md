## [결정] D1. 도주 설계 — 2026-07-03 제정 → **2026-07-04 대개정·구현 완료** ("핑은 언제나, 피격은 묻는다")

**발단**: 07-03 아침 라이브(seed7) 첫 전멸. HP 3/6 고블린 1마리가 3인 각개격파.
피른: 이동 order가 매번 접수("pathed")된 뒤 실행기에서 취소("encounter") — 좌표 (35,11)에 10틱 고정,
HP 11→-1, 자기 주문이 무효인 걸 관측할 방법 없음(reason은 끝까지 일관·합리적이었음).

**최종 설계 (2026-07-04, 파트너 단순화 — 구현·검증 완료)**: 도주는 별도 동사가 아니다.
모드도 스로틀도 없다. 필요한 것은 상태가 아니라 **사건(인터럽트)** 뿐이다.

1. **이동핑은 언제나 유효, 자동보행은 언제나 완주형.** 도주 = 후퇴 방향으로 핑을 찍는 것
   (파트너 명제: "이동핑 자체가 이미 의도의 피력"). 이탈 동사·버튼·전투모드·붙잡힘 규칙·SPD
   스로틀 전부 불요 — 검토 끝에 모두 기각(경로 기록 참조).
2. **피격 = 인터럽트.** 몬스터 공격이 명중하면 당한 봇의 진행 중 order 를 그 자리에서 비우고
   다음 틱 재결정을 요청한다(_monster_attack). 매복 일격도 같은 프리미티브(물림=각성).
3. **레벨 트리거 정지 2개 삭제**: step_order 의 pre_adj(걷기 전 인접몹 정지 — 피른을 죽인
   코드)와 이동 후 adj_mon(알던 몹 인접 정지). "아는 사실의 지속"은 정지 사유가 아니다(D2 전면
   적용). encounter 는 이제 *새 정보*(처음 보는 몹·함정·발견)만 뜻한다.
4. **봇은 자기 행동의 결과를 관측할 수 있어야 한다**(원칙 승격 — 존치): 엔진이 매 행동/피격
   결과를 `bot['last']`에 기록, view 가 `obs['last']`로 노출. 물린 봇이 "왜 멈췄는지"를 보고
   도주 핑을 고를 이유를 갖는다. 프롬프트에 물리 사실 명기("물리는 건 멈춰 있을 때다").
5. **기회공격 없음**(존치). 도주 비용은 세계가 청구: 추격, 가던 길의 상실, 도착지의 미지.
6. **물리 근거**: 걷는 봇은 동속 근접몹에게 잡히지 않는다(몹 공격 창=자기 턴 시작 시 직교
   인접 — 매 틱 한 칸씩 벗어나는 봇에겐 영원히 반 발 늦음. SPD 동일 물리). 위험은 멈추는
   순간(줍기·수색·대기) 청구되고, 그 순간의 피격이 정확히 재결정 질문을 만든다.
7. **갬빗 첫 표본(→⑤)은 "피격 인터럽트 시 반사 도주 핑"으로 재정렬** — 반사가 자동화할
   대상이 곧 이 핑이라 설계가 그대로 이어진다.

**구현 부산물 — 정지 규칙 삭제가 드러낸 잠복 livelock 2종(2026-07-04 스윕 실측·수정)**:
구 정지 규칙은 우연히 '교전 강제 개시 장치'이기도 했다. 삭제하자 (a)**위상잠금 궤도**: 움직이는
목표(몹 추격·동료 합류)의 order 가 path 소진으로 영영 안 끝나 봇이 못 멈추고, 못 멈추니 몹도
못 물던 무한 술래잡기(seed2) → **움직이는 목표의 도착 = 직교 인접 도달**로 완료(목표상태변화
인터럽트의 도착판) (b)**재경로 술래잡기**: 다음 칸을 점거한 몹을 조용한 재경로로 영원히 빙빙
돌던 문간 댄스(seed4 그림자거미) → **보이는 몹의 길목 점거 = blocked+monsters 로 멈춰 보고**
(경로 경합은 새 정보다. 조용한 재경로는 정보 은폐 = 원칙 4 위반이기도 했다. concealed 점거는
조용한 재경로 유지 — 존재 비누설).

**검증**: verify_interrupt.py(8번째 게이트) 신설 + 기존 7종 **어서션 무수정** ALL PASS +
300시드 종결성 스윕 0건 실패 + 실Haiku seed7 재도전 스모크.

경로 기록: 후퇴 동사(기회공격 포함) 제안 → 기각("이동으로 충분, 규칙만 픽스") → 재심 → 도주
핑+에지 트리거로 제정(07-03) → **07-04 파트너 연쇄 단순화가 전부 갈아엎음**: 이탈 버튼("심플하게
버튼 아닌가") → 붙잡힘 규칙 → 전투모드 스텝("전투 중 자동이동 금지") → SPD 원탭원스텝 스로틀 →
**"데미지를 입으면 멈추고 에이전트에게 묻는다"** = 핸드오프 결정점 루프의 재유도. Q4(이탈 이름)는
동사 자체가 소멸해 폐결이 무의미화. 파트너 위화감이 설계를 뒤집은 4번째 사례이자 최대 규모 —
"모드"를 발명하려던 시도가 전부 틀렸고 필요한 건 사건뿐이었다.

## [결정] D2. 인터럽트는 에지 트리거 — 2026-07-03 (헌법 조항)

## [통찰] S4. 결정점 루프의 조상 = 현재 틱 루프

order 자동보행 중 LLM 스킵="잠듦" / 인카운터 정지="인터럽트 각성" / arrived="목표상태변화".
차이 두 개뿐: ①분류기가 사소한 이벤트를 큐로 거름 ②반사 상황은 갬빗이 선점(LLM 미도달). 둘 다 호출 절감 방향.

```

           → 수면 윈도우: 큐 일괄 관측 + 갬빗 개정(배치)
```

## [결정] D5. 태그 시스템 = 채택, 설계 우선 — 2026-07-03 (미구현)

**방치형에서 태그 원장은 부가 기능이 아니라 제품 그 자체다** — 사용자는 플레이를 안 보므로 소비물은 기록뿐이고,
그 기록의 뼈대(서사적 구두점)가 태그다. 발주서 합격 기준("기록이 읽을 만한가")의 직접 담당자.
- **얇은 프리미티브(§5)**: `(종류, 대상, 원천 이벤트 참조, 월드시간, 수명)`.
  **대상 축 = 캐릭터 / 관계(캐릭터 쌍) / 파티 / 런** — 쌍을 1급 대상으로 두면 타 사용자 에이전트와의 조우도 같은 프리미티브로 흡수(다중 에이전트 관문).
- **발급 = 시스템 독점, 태그 발급기 = 스트림 소비자**(엔진→스트림→[…|태그 발급기] — GM 강등 형제 구조 3번째 반복. 엔진 무수정).
- **조건 어휘 = 스트림 이벤트로 닫힘**(say 텍스트 해석 금지 — LLM 발급은 환각 정문+결정론 파괴).
  거울 대칭: 갬빗은 봇의 눈(obs)을 읽고, 태그는 세계의 진실(stream)을 읽는다.
