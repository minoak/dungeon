# prompts/ — 이 세계의 말

**경계(2026-10-04 합의)**: 이 폴더 안은 파트너가 고치는 '말'이고, 밖은 코드다. 여기 적힌 문장이 사양이다 — 코드가 문장을 제 판단으로 바꾸지 않는다.
고친 뒤 `python tools/check_words.py` 한 번이면 된다(정의와 말 파일이 어긋난 곳을 전부 나열한다 · 실 LLM 0콜).

| 파일 | 누가 읽나 | 비고 |

| `social_prompt.md` | 모험가 — 사교 콜(대화 한마디) | 같은 PARTY/SOLO 표식 |

## 지킬 것 (파일 공통)

- `<!-- … -->` 안은 **사람용 메모** — 캐릭터·NPC 에게 가지 않는다(로더가 걷는다). PARTY/SOLO 표식만 예외.
- `{name}` 같은 **중괄호는 엔진이 채우는 자리** — 남긴다. 자리 이름을 바꾸면 그 자리가 빈 채로 간다.
- 지침 안의 **행동 이름·JSON 출력 형식**(응답은 JSON 한 줄 … 같은 줄)은 엔진이 읽는 열쇠 — 문장은 고쳐도 열쇠는 그대로.
- 저장은 UTF-8. 줄끝은 아무거나(CRLF 도 읽힌다).

## world/ — 엔티티의 말 (D100, 2026-10-06)

정의 `entities/<종류>/<id>.json` 은 숫자·규칙·식별자만 들고, 말은 같은 이름의 `prompts/world/<종류>/<id>.md` 가 든다.
정의의 그 칸에는 `"@prompts"` 표시만 남아 있고, 엔진이 둘을 합쳐 읽는다(`entities.read`). 이름(`name`)은 정의에 남는다(도감·대사 표·관전 화면의 열쇠).

```
# 성직자 · temple_attendant
<!-- 메모 -->
## `npc.line` — 첫 대사(말을 걸면 · 관전 말풍선)
기도를 들었어요. …
## `overheard` — 구역에 들어설 때 들리는 말(목록)
- 첫 줄
- 둘째 줄
```

- `## ` 뒤 **백틱 안 = 칸 이름**(정의 `comps` 아래 경로 — 엔진이 읽는 열쇠, 바꾸지 않는다). **줄표(—) 뒤 = 사람용 설명**(고쳐도 된다).
- **목록 칸**(`texts`·`wares`·`overheard`)은 한 줄에 하나씩 `- ` 로 시작한다. 나머지 칸은 본문 그대로(여러 줄도 된다 · 앞뒤 빈 줄은 걷는다).
- `life.…` 칸은 마을 생활을 켠 판에서 위 칸 **대신** 쓰이는 말(끈 판은 위 칸).
- **새 칸을 열려면** 정의 JSON 에 `"@prompts"` 자리를 먼저 만든다(자리 없는 칸은 읽히지 않고, 칸 없는 자리도 읽히지 않는다 — 둘이 어긋나면
  `check_words` 가 알려 주고, 게임도 같은 이유로 안 뜬다). 새 엔티티도 같다: JSON 한 장 + 말 파일 한 장.
- 정의가 없는 말 파일(초안)은 두어도 된다 — `check_words` 가 경고로만 찍는다.
- ⚠️ 몇몇 본문(옛 지식 7건·옛 마을 NPC 셋·새 몬스터 셋)은 `verify_entities` 가 해시로 고정해 둔다 — 고치면 그 게이트가 빨간불이 된다.
  고치지 말라는 뜻이 아니다. 해시를 옮기는 건 코드 쪽 일이니 고치고 알려 주면 된다.
